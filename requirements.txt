# FamilyHub v1 — direct dependencies only.
#
# TEACHING NOTE: This file used to be a full `pip freeze` of a polluted
# environment (it listed poetry, pipenv, keyring... tools that have nothing
# to do with this app). Best practice is to list ONLY the packages your app
# imports directly, pinned to exact versions so every machine — your Windows
# desktop, the Fedora ThinkPad, and the Lightsail server — installs the
# exact same code. Pip resolves the sub-dependencies (Jinja2, Werkzeug,
# alembic, ...) automatically.
#
# WGU connection: dependency management like this is a core DevOps idea
# you'll see again in D287 (Java Frameworks) as Maven's pom.xml — same
# concept, different language.
